# ⚡ Hi Plateg — Инновационная и Защищенная Платежная Панель

Премиальная платежная система, биллинговый шлюз и панель управления нового поколения с кибер-финтех дизайном (Glassmorphism), комплексной защитой и полнофункциональной панелью администратора.

---

## 🚀 Быстрый запуск

### Вариант 1. Автономный запуск в браузере (Мгновенно, без установки)
Просто откройте файл:
```
d:\Hi Plateg\public\index.html
```
в любом браузере (Google Chrome, Edge, Firefox, Safari). В интерфейс встроен интеллектуальный клиентский эмулятор, сохраняющий данные в `localStorage`.

### Вариант 2. Запуск через полноценный Node.js сервер
В терминале:
```bash
cd "d:\Hi Plateg"
node server.js
```
Откройте в браузере: **`http://localhost:3000`**

## 🌟 Ключевые возможности

### 1. Кабинет Мерчанта (Dashboard)
- **Финансовая аналитика**: Карточки баланса (Общий оборот, Доступно к выводу, Уплаченная комиссия, Выплачено), интерактивный график динамики оборота на Chart.js с неоновым градиентом.
- **Транзакции и реестр**: Поиск по ID/описанию, фильтры по статусам (*Успешно*, *В обработке*, *Отклонен*), экспорт транзакций в CSV.
- **Интерактивный чекаут**: Возможность создать счет на оплату и запустить симулятор клиентского платежного окна (СБП с QR-кодом, карты РФ МИР, криптовалюта USDT).
- **Вывод средств (Payout)**: Форма мгновенного запроса выплаты с авто-калькулятором комиссии.
- **API & Вебхуки**: Публичный и секретный ключи API, перевыпуск ключей, настройка адреса Webhook, примеры cURL запросов.
- **Безопасность**: Управление 2FA (TOTP), белый список доверенных IP-адресов.

### 2. Панель Администратора (SuperAdmin Panel)
- **Глобальный обзор**: Суммарный оборот всей платформы, чистый доход от комиссий, количество мерчантов, объем выплат.
- **Управление пользователями**: 
  - Просмотр всех зарегистрированных мерчантов;
  - Ручная корректировка баланса (+ / -);
  - Назначение персональной процентной ставки комиссии;
  - Блокировка и разблокировка аккаунтов.
- **Управление комиссиями**:
  - Базовая комиссия платформы;
  - Отдельные тарифы по каждому методу: **СБП QR**, **Карты МИР / РФ**, **Криптовалюта USDT TRC-20**, **P2P**;
  - Комиссия на вывод средств (Payout).
- **Настройки платформы**:
  - Включение / выключение Режима технических работ (Maintenance Mode);
  - Настройка минимальной и максимальной суммы единовременного платежа;
  - Переключатель автоматического антифрод-скоринга.
- **Журнал аудита & Безопасности**: Логирование всех критических действий, IP-адресов, смены тарифов и авторизаций.

## 🛡️ Архитектура безопасности
1. **Криптографическое хеширование паролей**: `PBKDF2-HMAC-SHA512` со случайной 16-байтной солью и 100 000 итерациями (защита от радужных таблиц и перебора).
2. **Timing-Safe сравнение**: `crypto.timingSafeEqual` предотвращает атаки по времени (Timing attacks) при проверке токенов и паролей.
3. **Ролевая модель (RBAC)**: Строгое разграничение доступа между мерчантами и администраторами на уровне middleware.
4. **Защита от XSS и инъекций**: Экранирование пользовательского контента в UI и валидация входящих типов данных на бэкенде.
5. **Rate Limiting**: Ограничение частоты запросов к API для предотвращения DoS и подбора паролей.
