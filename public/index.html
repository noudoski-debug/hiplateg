Ключи доступа

Пример: создать счёт через API

curl -X POST http://localhost:3000/api/transactions/create-invoice \
  -H "Authorization: Bearer hp_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 2990.00,
    "description": "Заказ #4912",
    "method": "sbp",
    "customerEmail": "buyer@mail.ru"
  }'

# ответ содержит payment_url — ссылку на страницу оплаты

Вебхук: оплата прошла

{
  "event": "invoice.paid",
  "invoice_id": "tx_9823412",
  "amount": 2990.00,
  "net_amount": 2945.15,
  "paid_method": "sbp",
  "paid_at": "2026-10-08T12:40:11.000Z",
  "signature": "sha256=..."
}

Подпись считается HMAC-SHA256 от тела запроса вашим secret key.
